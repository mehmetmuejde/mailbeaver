# 6. shadcn/ui as the UI component base

Date: 2026-10-17

## Status

Accepted

## Context

The UI grows from a single inbox into a mail client with navigation, toolbars, icon
buttons, dialogs, tooltips and button groups. Building accessible versions of all of
them by hand costs time and is easy to get wrong.

## Decision

The UI uses shadcn/ui: Radix primitives, Tailwind CSS v4 and lucide-react icons. The
components generated by the shadcn CLI live in `src/shared/ui/primitives/`; our own
components are built on top of them. The shadcn MCP server is configured for the
project (`.mcp.json`, `shadcn@4.22.0`).

## Consequences

- Accessible primitives (focus handling, ARIA, keyboard) come with the components.
- The generated code is ours and is updated through the CLI, not as a dependency.
- Styling moves from the hand-written stylesheet to Tailwind utility classes.
